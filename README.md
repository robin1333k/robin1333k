# Robin Klotz

I'm a UI/UX designer with a bachelor's degree in Information Design from Stuttgart Media University. I design complex things so that people understand them and connect with them.

This is where I keep tools I use myself. I design the concept and the interaction. I write the code together with AI.

### NextTyped

A macOS app that suggests the next words as you type, in any application. The language model runs locally on the Mac. Source code: [robin1333k/NextTyped](https://github.com/robin1333k/NextTyped)

### Color grading plugin for Final Cut Pro

Grading tools like those in DaVinci Resolve, inside Final Cut Pro. First built for my own camera, then extended to support other cameras.
