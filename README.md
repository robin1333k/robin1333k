Eine macOS-App, die beim Tippen in jeder Anwendung die nächsten Wörter vorschlägt. Das Sprachmodell läuft lokal auf dem Mac. Quellcode: [robin1333k/NextTyped](https://github.com/robin1333k/NextTyped)

### Color-Grading-Plugin für Final Cut Pro

Grading-Werkzeuge wie in DaVinci Resolve, direkt in Final Cut Pro. Zuerst für die eigene Kamera gebaut, dann für weitere Kameras ausgebaut.
